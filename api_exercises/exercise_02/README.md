# Exercise 02 — Classes, APIs and Pandas

A small Python exercise created to practice **Object-Oriented Programming**, **REST APIs**, and **Pandas**.

## Concepts Practiced

* Creating and using Python classes
* Separating code into modules
* Performing HTTP requests with `requests`
* Working with `GET` and `POST` requests
* Using API parameters and endpoints
* Reading JSON responses
* Converting JSON data into Pandas DataFrames

## API

This exercise uses the **JSONPlaceholder API**, a free REST API designed for testing and learning.

The `JsonPlaceholderAPI` class currently supports:

* Getting all posts
* Getting a post by ID
* Getting posts by user ID
* Creating a new post

## Libraries

* `requests`
* `pandas`
