# MiniCore — Inventory Management System

## Goal
Build a command-line inventory management system using Python.

The system will store random products, allowing users to register, search, update, delete, organize, and analyze inventory data.

## Initial Features
- Register products.
- List all products.
- Search products by ID or name.
- Update product information.
- Delete products.
- Generate basic inventory statistics.

## Data Structure
Start with a list of dictionaries.

Gradually incorporate:
- Lists, tuples, sets and dictionaries.
- List and dictionary comprehensions.
- `*args` and `**kwargs`.
- Filtering, sorting and aggregation.
- Nested data structures.

## Future Improvements
1. Advanced search and filtering.
2. Inventory reports and analytics.
3. Multiple warehouses and stock redistribution.
4. JSON persistence.
5. OOP and modular architecture.
6. SQLite integration.

## Development Rules
- Start simple and expand gradually.
- Prioritize problem-solving over syntax.
- Write functions with increasingly complex logic.
- Avoid unnecessary code duplication.
- Consider edge cases and input validation.
- Refactor older code as new concepts are learned.

**Main objective:** Practice Python data structures, functions, and logical problem-solving by continuously expanding a single project.

No rush. Build, break, debug, and improve.
